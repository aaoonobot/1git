# Supplementary Outputs

This folder is intended for compact statistical outputs used to verify the results reported in the manuscript.

Recommended files include:

- `xpass_test_metrics.csv`
- `xpass_val_curve.csv`
- `xpass_best_threshold.txt`
- `xpass_oof_metrics.csv`
- `risk_reward_descriptive_stats.csv`
- `pressure_height_summary.csv`
- `threshold_bootstrap.csv`
- `xpass_sensitivity_summary.csv`
- `risk_structural_sensitivity_summary.csv`
- `risk_formula_sensitivity_summary.csv`
- `leverkusen_case_outputs.csv`

Large event-level CSV files should not be committed to the repository. They can be regenerated with the scripts or archived separately using Zenodo, OSF, or Figshare.
