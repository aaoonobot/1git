# Reproducibility notes

## Analysis units

All predictive model splits and cross-fitting folds are defined at match level.
The locked independent xPass evaluation uses 2,747 training matches, 395 tuning
matches, 394 calibration matches, and 390 test matches. Downstream pass-value
estimates use match-level out-of-fold predictions.

## Primary samples

- Primary open-play sample: 3,396,912 passes from 3,926 matches.
- Strict open-play sensitivity sample: 1,754,809 passes.
- Three-team application: 54,795 focal-team passes from 110 matches.
- Player application: 80 players; the primary eligibility rule retains
  55 players with at least 200 passes and at least five matches.

## Downstream workflow

1. Run `13_team_player_analysis.py` on the H=3 pass-value file and the fixed
   three-team event cohort.
2. Run `14_finalize_team_player_tables.py` to add the full-sample reference,
   centered values, eligibility checks, and eligible-only ranks.
3. Run `15_robustness_analysis.py` with H=1, H=3, and H=5 pass-value files.
4. Run `16_robustness_reporting.py` after the selected player pairs have been
   generated by the player-level analysis.
5. Run `17_full_sample_analysis.py` for Figure 2 and Supplementary Figure S3.
6. Run `18_three_team_analysis.py` for Figure 3 and the deterministic
   three-team event cohort.
7. Run `19_prepare_player_events.py` to attach player and position metadata.
8. Run `20_player_decision_value_analysis.py` for Figure 4.

## Fixed three-team manifest

For exact reproduction, pass
`data/manifests/three_team_match_manifest.csv` to
`18_three_team_analysis.py --cohort_manifest_csv`. The match metadata file is
only required when the cohort is to be reconstructed automatically.

## Uncertainty

Reported confidence intervals use nonparametric match-cluster bootstrap
resampling. The standard number of repetitions is 1,000 unless a script
explicitly documents another value.

## Output integrity

The analysis modules write audit JSON files and, where applicable, SHA-256
manifests. Preserve the scripts, input manifests, audit records, terminal logs,
and generated hash files together when freezing a release.
